📖 How to Set Up the Bot

  1. Open Telegram and search for @BotFather.
  2. Send the command /newbot and follow the instructions to get a token.
  3. Save the token using this dashboard (Setup Wizard or System Settings).
  4. Create your Telegram Group (or open your existing group).
  5. Add the bot user as a member of your group.
  6. Open the Group Info, go to **Administrators**, add the bot, and allow **Delete Messages** and **Ban Users**.
  7. Your group is now protected! The dashboard will start plotting stats dynamically.
